# How to request your own USRBG banner

Join [Black Box Discord Server](https://discord.gg/ECg96KZ3Fh) and follow the instructions in [#usrbg-guide](https://discord.com/channels/449175561529589761/886287835018178560).

> [!WARNING]  
> This is NOT the "Blackbox" Discord Server (discord.gg/blackbox), which is an unrelated iOS puzzle game and has no ability to set user backgrounds.

All requests are processed manually by a select few moderators. You should expect to wait a decent amount of time before your background is approved.

Do not ask me about getting banned in Black Box, I am not even in the server.
